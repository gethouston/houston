Every word here is explained the first time it shows up in a lesson. This page collects them. The Spanish name is in *italics*, because you'll see both in tools and docs.

## A–F

**API** · *API*
A way for one program to ask another for something. Like a waiter between programs. [Lesson](/course-1/apis/)

**API docs** · *documentación de la API*
The "menu" of an API: what you can ask for, and how.

**API key** · *clave de API*
A secret string that proves a request comes from you, so the company can limit or bill you. Like a hotel key card. Never put one in a page. [Lesson](/course-1/api-keys/)

**Backend** · *backend*
The part of an app that runs on a server, out of sight: where secrets, data and rules live. Its opposite is the frontend.

**Browser** · *navegador*
The app you use to open websites: Chrome, Safari, Edge.

**Browser pane** · *panel del navegador*
The preview inside the Claude desktop app, where Claude shows what it built.

**Client** · *cliente*
The program that asks: usually your browser or your phone app. The server answers.

**Claude desktop app** · *app de escritorio de Claude*
Your workbench in this program. Its **Code** tab lets Claude work on the files in a folder on your computer.

**Deploy / publish** · *desplegar / publicar*
Copy your app to a server, so anyone with the address can use it. [Lesson](/course-0/3-publish/)

**"Done when"** · *"listo cuando"*
A sentence that says how anyone can check a slice is finished, without reading code. Also called acceptance criteria.

**Endpoint** · *endpoint*
One specific thing you can ask an API for, like "current weather". One item on the menu.

**Environment variable** · *variable de entorno*
A setting kept outside the code, often a secret like an API key. Course 4.

**Folder / file** · *carpeta / archivo*
A project is a folder. Your page is a file in it (`index.html`).

**Frontend** · *frontend*
The part of an app that runs in the user's browser: what they see and click. Anyone can read it.

## H–Z

**Hosting** · *hosting / alojamiento*
Renting a server to keep your app online. Vercel is a hosting company.

**HTTPS** · *HTTPS*
The secure way browsers talk to servers. Addresses that start with `https://` are encrypted on the way.

**Localhost** · *localhost*
"This computer." An address only you can open, used for previews.

**Permission request** · *solicitud de permiso*
When Claude asks before creating, changing or running something. Read it before you click.

**Plugin** · *plugin*
An add-on for Claude. The Academy tutor is a plugin called `academy`.

**Preview** · *vista previa*
Seeing what Claude built, on your computer, before it's published.

**Prompt** · *prompt / instrucción*
What you write to Claude.

**Request / response** · *solicitud / respuesta*
What a program asks for, and what comes back.

**Server** · *servidor*
A computer that's always on and connected, answering requests from clients.

**Session** · *sesión*
One conversation with Claude in the Code tab, tied to one project folder.

**Slice** · *rebanada*
A small piece of your product that works from start to finish and can be tested in minutes. [Lesson](/course-2/gta-6-problem/)

**URL** · *URL / dirección*
The address of a page, like `https://my-corner.vercel.app`.

**Vercel** · *Vercel*
The hosting company the program uses. Free for small projects.
