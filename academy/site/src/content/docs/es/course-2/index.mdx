La mayoría de la gente abre un agente de IA y escribe su sueño completo: *"Hazme GTA 6, pero multijugador."* Nunca funciona, y la razón no es la IA. **Nadie puede construir ni probar todo de una vez.** Este curso enseña el método detrás de cada proyecto del programa: **el Ciclo del Constructor**.

> **Idea → problema → la versión útil más pequeña → rebanadas → para cada rebanada: "listo cuando" → Claude planea → tú apruebas → Claude construye → tú pruebas → gente real lo usa → tú decides qué sigue.**

## El proyecto del curso

*Tu producto, rebanada 1:* escoge tu idea, escribe un brief de una página y sus rebanadas, publica la rebanada 1 como un prototipo en el que se puede hacer clic, y pruébalo con 3 personas.
